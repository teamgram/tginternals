# PaidReactionPrivacy
Paid reaction privacy settings »

```
paidReactionPrivacyDefault#206ad49e = PaidReactionPrivacy;
paidReactionPrivacyAnonymous#1f0c1ad9 = PaidReactionPrivacy;
paidReactionPrivacyPeer#dc6cfcf0 peer:InputPeer = PaidReactionPrivacy;
```

## Constructors
| Constructor | Description |
| ---- | ----------- |
| paidReactionPrivacyDefault | Uses the default reaction privacy, set using messages.togglePaidReactionPrivacy. |
| paidReactionPrivacyAnonymous | Send paid reactions anonymously. |
| paidReactionPrivacyPeer | Send paid reactions as the specified peer, fetched using channels.getSendAs. |
