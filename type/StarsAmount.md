# StarsAmount
Describes a real (i.e. possibly decimal) amount of Telegram Stars.

```
starsAmount#bbb6b4a3 amount:long nanos:int = StarsAmount;
starsTonAmount#74aee3e0 amount:long = StarsAmount;
```

## Constructors
| Constructor | Description |
| ---- | ----------- |
| starsAmount | Describes a real (i.e. possibly decimal) amount of Telegram Stars. |
| starsTonAmount | Describes an amount of toncoin in nanotons (i.e. 1/1_000_000_000 of a toncoin). |
