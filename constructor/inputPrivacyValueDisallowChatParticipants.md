# inputPrivacyValueDisallowChatParticipants
Disallow only participants of certain chats

```
inputPrivacyValueDisallowChatParticipants#e94f0f86 chats:Vector<long> = InputPrivacyRule;
```

## Parameters
| Name | Type | Description |
| ---- | :----: | ----------- |
| chats | Vector<long> | Disallowed chat IDs (either a chat or a supergroup ID, verbatim the way it is received in the constructor (i.e. unlike with bot API IDs, here group and supergroup IDs should be treated in the same way)). |


## Type
InputPrivacyRule
