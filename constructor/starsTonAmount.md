# starsTonAmount
Describes an amount of toncoin in nanotons (i.e. 1/1_000_000_000 of a toncoin).

```
starsTonAmount#74aee3e0 amount:long = StarsAmount;
```

## Parameters
| Name | Type | Description |
| ---- | :----: | ----------- |
| amount | long | The amount in nanotons. |


## Type
StarsAmount
