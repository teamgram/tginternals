# privacyValueDisallowChatParticipants
Disallow only participants of certain chats

```
privacyValueDisallowChatParticipants#41c87565 chats:Vector<long> = PrivacyRule;
```

## Parameters
| Name | Type | Description |
| ---- | :----: | ----------- |
| chats | Vector<long> | Disallowed chats IDs (either a chat or a supergroup ID, verbatim the way it is received in the constructor (i.e. unlike with bot API IDs, here group and supergroup IDs should be treated in the same way)). |


## Type
PrivacyRule
