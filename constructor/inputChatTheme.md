# inputChatTheme
Set an emoji-based chat theme, returned by account.getChatThemes.

```
inputChatTheme#c93de95c emoticon:string = InputChatTheme;
```

## Parameters
| Name | Type | Description |
| ---- | :----: | ----------- |
| emoticon | string | The emoji. |


## Type
