# inputMediaPaidMedia
Paid media, see here » for more info.

```
inputMediaPaidMedia#c4103386 flags:# stars_amount:long extended_media:Vector<InputMedia> payload:flags.0?string = InputMedia;
```

## Parameters
| Name | Type | Description |
| ---- | :----: | ----------- |
| flags | # | Flags, see TL conditional fields |
| stars_amount | long | The price of the media in Telegram Stars. |
| extended_media | Vector<InputMedia> | Photos or videos. |
| payload | flags.0?string | Bots only, specifies a custom payload that will then be passed in updateBotPurchasedPaidMedia when a payment is made (this field will not be visible to the user) |


## Type
InputMedia
