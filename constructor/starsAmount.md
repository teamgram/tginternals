# starsAmount
Describes a real (i.e. possibly decimal) amount of Telegram Stars.

```
starsAmount#bbb6b4a3 amount:long nanos:int = StarsAmount;
```

## Parameters
| Name | Type | Description |
| ---- | :----: | ----------- |
| amount | long | The integer amount of Telegram Stars. |
| nanos | int | The decimal amount of Telegram Stars, expressed as nanostars (i.e. 1 nanostar is equal to 1/1'000'000'000th (one billionth) of a Telegram Star). This field may also be negative (the allowed range is -999999999 to 999999999). |


## Type
StarsAmount
